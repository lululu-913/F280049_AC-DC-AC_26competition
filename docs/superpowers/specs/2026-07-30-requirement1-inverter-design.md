# 基本要求1逆变控制设计

## 目标

在保留现有主动整流控制和40kHz控制中断的前提下，使三相逆变部分以20kHz SVPWM输出60Hz三相对称交流电，线电压目标为32Vrms。

## 控制参数

- 输出线电压目标：32Vrms。
- 输出相电压目标：`32 / sqrt(3) = 18.4752Vrms`。
- 输出频率默认值：60Hz；保留KEY2切换30Hz的现有功能。
- 直流母线额定值：55V。
- 55V母线下的初始公共调制度：约0.4752。
- 初始调制分母：`M = 55 * sqrt(3/2) / 32 = 2.1044`。
- 保留`M`的1.8～8.0范围及0.56公共调制度限幅，不增加母线启动门槛。

## 启动时序

ADC和控制ISR为40kHz，而逆变ePWM1～3的CMPA仅在20kHz载波零点装载。首次写入逆变CMPA影子寄存器后等待两个控制ISR事件，再清除ePWM1～3的One-Shot Trip，保证无论首次写入发生在载波零点还是周期点，新CMPA活动值都已完成装载。

## 负载条件

程序调节输出电压，不直接调节2A输出线电流。星形电阻负载下，每相电阻应约为`18.4752V / 2A = 9.24Ω`，并应具有足够功率裕量。

## 验证

- 策略测试检查32V线电压参考、55V母线下的初始调制度、60Hz默认频率和两拍Trip释放等待。
- 运行现有SVPWM和便携控制算法测试。
- 使用CCS Debug配置完整编译和链接。
- 不改动整流ePWM4/5、ADC触发源及40kHz控制周期。
